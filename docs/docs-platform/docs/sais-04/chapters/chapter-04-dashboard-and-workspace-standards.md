# Chapter 4 — Dashboard & Workspace Standards

> **Normative**
>
> Every learner dashboard, instructor workspace, mentor workspace, administrator console, AI workspace, and learner-facing home experience within Simplicion Academy SHALL comply with the Dashboard & Workspace Standards defined in this chapter.

---

# 4.1 Purpose

The dashboard is the primary workspace where users interact with the Academy.

It should answer three questions immediately:

- What should I do now?
- What have I accomplished?
- What should I learn next?

Every workspace SHALL provide the right information, actions, and insights based on the user's role, goals, and current progress.

---

# 4.2 Objectives

This chapter establishes standards for:

- Dashboard Architecture
- Workspace Layout
- Dashboard Types
- Widget Framework
- Personalization
- AI Workspace
- Notifications
- Calendar
- Productivity Tools
- Dashboard Analytics
- Workspace Governance

---

# 4.3 Dashboard Philosophy

The Academy adopts the following philosophy.

> **A dashboard is an action center—not merely a reporting page.**

Every dashboard SHALL:

- prioritize current work
- minimize distractions
- surface important insights
- encourage progress
- adapt to the user
- support rapid decision-making

---

# 4.4 Canonical Dashboard Architecture

Every learner workspace SHALL follow the canonical dashboard architecture.

```text
Dashboard
   │
   ▼
Today's Focus
   │
   ▼
Continue Learning
   │
   ▼
Recommended Learning
   │
   ▼
Upcoming Activities
   │
   ▼
Progress
   │
   ▼
Achievements
   │
   ▼
AI Assistant
   │
   ▼
Notifications
   │
   ▼
Calendar
   │
   ▼
Quick Actions
```

The dashboard SHALL emphasize current priorities before secondary information.

# 4.5 Dashboard Types

The Academy SHALL support multiple dashboards.

Representative dashboards include:

| Dashboard | Primary User |
|------------|--------------|
| Learner Dashboard | Learners |
| Instructor Dashboard | Instructors |
| Mentor Dashboard | Mentors |
| Organization Dashboard | Enterprise Administrators |
| Academy Dashboard | Platform Administrators |

Each dashboard SHALL optimize for its intended audience.

---

# 4.6 Learner Dashboard

The Learner Dashboard SHALL include:

- Continue Learning
- Daily Learning Goal
- Learning Progress
- Current Learning Path
- Upcoming Assessments
- AI Recommendations
- Recent Activity
- Achievements
- Notifications
- Calendar
- Bookmarks
- Certificates

The learner SHALL always be able to resume learning with one interaction.

---

# 4.7 Instructor Dashboard

Instructor workspaces SHOULD provide:

- course management
- learner progress
- assignment review
- assessment results
- discussion management
- announcements
- analytics
- AI teaching assistant

The instructor workspace SHALL prioritize teaching activities.

---

# 4.8 Mentor Dashboard

Mentors SHOULD receive:

- assigned learners
- learner progress
- mentoring sessions
- learner questions
- recommendations
- meeting schedule
- AI insights

Mentor dashboards SHALL support personalized guidance.

---

# 4.9 Organization Dashboard

Enterprise administrators MAY access:

- learner analytics
- organization progress
- compliance training
- certification status
- reporting
- user management
- licensing
- operational metrics

Organization dashboards SHALL support strategic oversight.

---

# 4.10 Workspace Layout

Every dashboard SHALL organize information using the following hierarchy.

```text
Primary Actions
      │
      ▼
 Current Work
      │
      ▼
   Progress
      │
      ▼
Recommendations
      │
      ▼
   Insights
      │
      ▼
   History
      │
      ▼
   Settings
```

The most important actions SHALL appear first.

- Continue Assessment

- Join Discussion
- View Calendar
- Download Certificate
- Review Notes
- Start Practice
- Bookmark Lesson

- AI Study Planner
- AI Search
- AI Revision Assistant

- AI Coding Assistant

# 4.14 Notifications

Notification systems SHALL prioritize relevance.

Representative notification categories include:

- learning reminders
- assignment deadlines
- assessment availability
- certificate issuance

- discussion activity
- achievement milestones

- lessons
- assessments
- mentoring sessions
- live classes
- deadlines
- community events
- certifications

---

# 4.16 Personalization

Dashboard personalization MAY consider:

- learning goals
- enrolled courses
- recent activity
- learning pace
- completed competencies
- preferred learning schedule
- AI recommendations

---

# 4.17 Workspace Productivity

Productivity tools MAY include:

- bookmarks
- notes
- study planner
- learning streak
- Pomodoro timer
- downloadable resources
- progress history
- task checklist

Productivity features SHALL reduce friction during learning.

---

# 4.18 Cross-Device Experience

Dashboard experiences SHALL remain consistent across:

- desktop
- tablet
- mobile
- future Academy platforms

Progress SHALL synchronize across supported devices.

---

# 4.19 Accessibility

Dashboards SHALL support:

- keyboard navigation
- screen readers
- scalable typography
- high-contrast modes
- captions
- responsive layouts
- reduced motion preferences

Accessibility SHALL comply with SAFS-04.

---

# 4.21 Workspace Governance

Dashboard governance SHALL define:

- widget ownership
- personalization rules
- accessibility reviews
- analytics ownership
- AI governance
- release approvals

Workspace governance SHALL maintain consistency across products.

---

Before publishing a dashboard or workspace, the following SHALL be verified:

✓ Dashboard architecture implemented

✓ Widget framework validated

✓ Personalization configured

✓ AI workspace reviewed

✓ Notifications operational

✓ Calendar integrated

✓ Accessibility verified

✓ Analytics configured

✓ Governance approved

---

# 4.23 Governance Integration

Dashboard & Workspace Standards SHALL integrate with:

- SAFS-03 Component Standards
- SAFS-04 Design Standards
- SAFS-05 Content Standards
- SAFS-06 Governance & Lifecycle Standards
- SAIS-04 Chapters 1–3

Every workspace SHALL remain consistent with the Academy's overall learning experience.

---

# 4.24 Normative Requirements

The following requirements are mandatory.

1. Every Academy product SHALL provide a role-appropriate dashboard.
2. Dashboards SHALL follow the canonical dashboard architecture.
3. Dashboard widgets SHALL be modular and reusable.
4. Users SHALL be able to resume active learning with minimal interaction.
5. AI-powered workspaces SHALL provide transparent and explainable assistance.
6. Personalization SHALL adapt to learner goals while respecting privacy and governance.
7. Dashboards SHALL synchronize across supported devices.
8. Dashboard accessibility SHALL comply with SAFS-04.
9. Dashboard effectiveness SHALL be measured using standardized KPIs.
10. Dashboard & Workspace Standards SHALL remain technology, platform, and vendor independent.
