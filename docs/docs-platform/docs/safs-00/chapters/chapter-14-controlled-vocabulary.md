# Chapter 14 — Controlled Vocabulary

> **A controlled vocabulary ensures that every person, document, platform component, and AI system uses the same words to describe the same concepts.**

---

# 14.1 Purpose

This chapter establishes the official vocabulary for Simplicion Academy.

A controlled vocabulary eliminates ambiguity by assigning one approved term to each educational concept.

All documentation, software, APIs, databases, user interfaces, AI systems, and learning content MUST use the approved terminology defined in this chapter.

---

# 14.2 Objectives

The controlled vocabulary exists to:

- Improve consistency
- Reduce ambiguity
- Standardize communication
- Improve search accuracy
- Improve AI interpretation
- Improve analytics
- Simplify onboarding
- Support long-term governance

---

# 14.3 Vocabulary Rules

The following rules apply to all official documentation.

- Every concept MUST have one approved term.
- Approved terms MUST be used consistently.
- Deprecated terms MUST NOT appear in new documentation.
- Synonyms MAY be recorded for search purposes but MUST NOT replace approved terms.
- New terminology MUST be approved through the Foundation Standards governance process.

# 14.12 Search Synonyms

To improve search and AI retrieval, the platform MAY maintain synonym mappings.

Example mappings:

| Search Term | Canonical Term |
|-------------|----------------|
| Lesson | Learning Unit |
| Course | Track |
| Test | Assessment |
| Study Material | Resource |
| File | Asset |
| Quiz | Knowledge Check |
| Program | Learning Path |

These mappings support search but MUST NOT replace canonical terminology in published content.

---

# 14.13 Vocabulary Governance

Vocabulary changes require:

- Review by the Academy Standards Team.
- Assessment of impact on existing documentation.
- Approval through the Foundation Standards governance process.
- Publication of updated terminology.
- Version increment where applicable.

Vocabulary changes should remain infrequent to preserve long-term consistency.

---

# 14.14 Common Mistakes

Avoid:

- Using multiple terms for the same concept.
- Creating unofficial abbreviations.
- Introducing new terminology without approval.
- Mixing legacy and approved vocabulary.
- Using informal or ambiguous language in standards documentation.
