# Chapter 7 — Assessment Object Definitions

> **Assessment exists to verify competency, not merely completion.**

---

# 7.1 Purpose

This chapter establishes the official assessment objects used throughout Simplicion Academy.

Assessments provide measurable evidence that a learner has achieved the intended learning outcomes and competencies.

No assessment object may be introduced outside this standard without formal approval.

---

# 7.2 Assessment Philosophy

Assessment in Simplicion Academy is based on five principles:

- Outcome-Oriented
- Competency-Based
- Practical First
- Continuous Feedback
- Evidence Driven

The goal is not to test memory alone but to validate understanding, application, and real-world performance.

---

# 7.3 Assessment Hierarchy

```text
Assessment
│
├── Knowledge Check
├── Practice Exercise
├── Assignment
├── Practical Task
├── Project
├── Peer Review
├── Portfolio Review
├── Final Assessment
└── Certification Evaluation
```

Each assessment object serves a distinct purpose and should not be used interchangeably.

---

# 7.4 Assessment

## Definition

An Assessment is any structured activity used to measure a learner's knowledge, skill, competency, or performance against predefined learning outcomes.

Every assessment MUST map to one or more learning objectives.

---

# 7.5 Knowledge Check

## Definition

A short evaluation used to verify immediate understanding of recently learned concepts.

### Examples

- Multiple-choice quiz
- True or false
- Fill in the blanks
- Matching exercise

Knowledge Checks are formative and should provide immediate feedback.

---

# 7.6 Practice Exercise

## Definition

A guided activity that allows learners to apply a concept without formal grading.

### Characteristics

- Low stakes
- Repeatable
- Feedback-oriented
- Supports mastery

---

# 7.7 Assignment

## Definition

A structured task requiring learners to demonstrate understanding through independent work.

Assignments may include:

- Written responses
- Design work
- Coding tasks
- Business analysis
- Research summaries

Assignments are generally evaluated against a rubric.

---

# 7.8 Practical Task

## Definition

A hands-on activity designed to demonstrate the application of a specific skill in a realistic context.

### Examples

- Build an API endpoint
- Design a wireframe
- Create an AI prompt workflow
- Conduct a customer interview

Practical Tasks emphasize execution over theory.

---

# 7.9 Project

## Definition

A Project integrates multiple skills and competencies into a meaningful outcome.

Projects should resemble real-world work and encourage problem-solving, creativity, and collaboration.

Tracks SHOULD include at least one capstone Project.

---

# 7.10 Peer Review

## Definition

A structured evaluation performed by other learners using predefined criteria.

Peer Review encourages collaboration, critical thinking, and constructive feedback.

Peer evaluations SHOULD complement, not replace, instructor evaluation.

---

# 7.11 Portfolio Review

## Definition

An evaluation of a learner's collection of completed work to determine demonstrated competency over time.

Portfolios provide long-term evidence of growth and capability.

---

# 7.12 Final Assessment

## Definition

The comprehensive evaluation used to determine whether the learner has achieved the required learning outcomes for a Module, Track, or Learning Path.

A Final Assessment may combine:

- Written evaluation
- Practical demonstration
- Project presentation
- Viva or interview
- Portfolio evidence

---

# 7.13 Certification Evaluation

## Definition

The final verification process required before awarding an official Simplicion Academy certification.

Certification Evaluations must confirm that all required competencies have been demonstrated.

Completion alone does not guarantee certification.

---

# 7.14 Assessment Metadata

Every assessment object MUST define:

- Immutable Identifier
- Title
- Assessment Type
- Associated Learning Objectives
- Associated Competencies
- Difficulty Level
- Passing Criteria
- Estimated Duration
- Evaluation Method
- Version
- Owner
- Lifecycle Status

---

# 7.15 Mapping Requirements

Every assessment MUST map to:

- At least one Learning Unit.
- At least one Learning Objective.
- One or more Competencies.
- A measurable evaluation criterion.

This mapping ensures traceability from instruction to evaluation.

---

# 7.16 Assessment Principles

Assessment design SHOULD:

- Measure application, not memorization alone.
- Encourage authentic problem-solving.
- Provide meaningful feedback.
- Align with industry practices.
- Support learner improvement.

---

# 7.17 Common Mistakes

Avoid:

- Assessments with unclear objectives.
- Grading without published criteria.
- Projects unrelated to learning outcomes.
- Duplicate assessments measuring the same competency.
- Evaluating completion instead of demonstrated ability.

# Summary

Assessment objects provide the official mechanism for validating learner competency throughout Simplicion Academy.

Every assessment must be purposeful, measurable, competency-linked, and traceable to defined learning outcomes.

Future standards will define scoring models, rubrics, competency mappings, analytics, and certification workflows.
