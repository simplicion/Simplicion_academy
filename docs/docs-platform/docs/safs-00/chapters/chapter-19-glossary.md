# Chapter 19 — Glossary

> **This glossary serves as the official reference for terminology used throughout Simplicion Academy Foundation Standards (SAFS). All terms shall be interpreted according to the definitions provided in this glossary unless explicitly stated otherwise.**

---

# 19.1 Purpose

The Glossary provides a centralized reference for the official terminology used across Simplicion Academy.

It exists to:

- Establish a single source of truth.
- Eliminate ambiguity.
- Improve consistency.
- Support documentation.
- Improve AI interpretation.
- Standardize communication.

---

# 19.2 Usage

This glossary applies to:

- SAFS Documents
- SACOS Documents
- Academy Documentation
- Platform Documentation
- APIs
- Educational Content
- Technical Documentation
- Internal Operations

Whenever a defined term appears in Foundation Standards, it carries the meaning specified in this glossary.

---

# 19.3 Glossary

| Term | Definition |
|------|------------|
| Academy | The complete Simplicion Academy learning ecosystem. |
| Activity | A structured learner action designed to reinforce learning. |
| AI | Artificial Intelligence systems supporting educational and operational tasks. |
| AI Agent | An autonomous or semi-autonomous AI system capable of executing defined workflows. |
| AI Assistant | An AI-powered system that provides guidance, explanations, recommendations, or support. |
| Assessment | A structured evaluation used to measure learning outcomes or competencies. |
| Asset | A reusable supporting resource such as a document, image, template, or video. |
| Career | A long-term professional journey involving continuous growth and development. |
| Career Path | A structured progression toward one or more career goals. |
| Certification | Official recognition awarded after successful completion of defined requirements. |
| Competency | Demonstrated ability to apply knowledge and skills effectively. |
| Controlled Vocabulary | The approved terminology used throughout the Academy. |
| Curriculum | The structured collection of Learning Paths, Tracks, Modules, and educational content. |
| Diagram | A visual representation of relationships, structures, or processes. |
| Document | A structured written resource maintained within the Academy. |
| Educational Asset | A reusable supporting resource that enhances learning. |
| Future Term | A proposed or newly approved term introduced through governance. |
| Knowledge Check | A short formative assessment used to verify understanding. |
| Learning Block | The smallest reusable instructional component. |
| Learning Outcome | A measurable statement describing what a learner is expected to achieve. |
| Learning Path | A collection of related Tracks leading toward broader educational goals. |
| Learning Unit | The smallest independently teachable instructional object. |
| Metadata | Structured information describing an educational object. |
| Module | A reusable collection of related Sections focused on a competency or subject. |
| Normative Language | Standardized obligation keywords defining requirement levels. |
| Object Identifier | An immutable identifier assigned to an educational object. |
| Portfolio | A curated collection of learner work demonstrating competencies. |
| Project | A practical activity demonstrating integrated application of learning. |
| Prompt | An instruction provided to an AI system to generate an output. |
| Prompt Engineering | The practice of designing prompts to improve AI-generated responses. |
| Resource | Supporting material that supplements instructional content. |
| Section | A logical grouping of related Topics within a Module. |
| Skill | A learned ability to perform a task effectively. |
| Standard | A documented requirement establishing consistent practices. |
| Topic | A focused subject area within a Section. |
| Track | A structured learning program designed to achieve a defined competency or career outcome. |
| Version | The official revision number assigned to a document or educational object. |

# 19.4 Alphabetical Reference

The glossary shall be maintained in alphabetical order to improve discoverability and simplify navigation.

When introducing new terms:

- Insert them alphabetically.
- Preserve existing definitions.
- Update related cross-references.
- Record the revision in the document history.

---

# 19.5 Definition Rules

Every glossary definition should:

- Describe a single concept.
- Be concise.
- Be technically accurate.
- Avoid circular definitions.
- Use approved terminology.
- Remain consistent with Foundation Standards.

# 19.7 Governance

The Glossary is governed under Simplicion Academy Foundation Standards.

Changes to glossary entries require:

- Review
- Approval
- Version update
- Publication
- Documentation of changes

Definitions shall not be modified without governance approval.

---

# 19.8 Common Mistakes

Avoid:

- Defining the same concept multiple ways.
- Introducing unofficial terminology.
- Using deprecated terms.
- Creating vague or overly broad definitions.
- Omitting glossary updates after introducing new concepts.
