# Chapter 8 — Skills & Competency Definitions

> **Skills define what a learner can do. Competencies define how effectively a learner can apply those skills in real-world situations.**

---

# 8.1 Purpose

This chapter establishes the official definitions for Skills, Competencies, Learning Outcomes, and Proficiency Levels within Simplicion Academy.

These definitions are mandatory for curriculum design, assessments, certifications, learner analytics, AI systems, and platform implementation.

---

# 8.2 Skill

## Definition

A Skill is a specific learned ability that enables a learner to perform a particular task or activity.

Skills are developed through learning, practice, and experience.

---

## Characteristics

- Observable
- Learnable
- Measurable
- Transferable
- Practical

---

## Examples

- Prompt Engineering
- API Development
- UI Design
- Market Research
- Public Speaking
- Video Editing
- Git Version Control

---

# 8.3 Competency

## Definition

A Competency is the demonstrated ability to apply one or more Skills, Knowledge, and Behaviors to successfully complete a real-world task.

Competencies represent verified capability rather than theoretical understanding.

---

## Characteristics

- Demonstrated
- Measurable
- Outcome-focused
- Evidence-based
- Assessable

---

## Examples

- Design a complete mobile application interface.
- Build and deploy a REST API.
- Create an AI workflow for business automation.
- Conduct customer discovery interviews.
- Deliver a professional investor pitch.

---

# 8.4 Knowledge

## Definition

Knowledge is the understanding of concepts, facts, principles, theories, and information related to a subject.

Knowledge provides the foundation upon which Skills are developed.

---

## Examples

- Understanding HTTP methods
- Knowing design principles
- Understanding AI prompting techniques
- Learning startup terminology

---

# 8.5 Learning Outcome

## Definition

A Learning Outcome describes what a learner is expected to know, understand, or be able to do after completing a learning experience.

Learning Outcomes must be measurable and observable.

---

## Characteristics

Every Learning Outcome should be:

- Clear
- Specific
- Measurable
- Achievable
- Relevant

---

## Example

After completing this Module, the learner will be able to:

- Design responsive user interfaces.
- Create reusable AI prompts.
- Build REST APIs.
- Validate startup ideas using customer interviews.

---

# 8.6 Competency Levels

Competencies are measured using progressive proficiency levels.

| Level | Name | Description |
|--------|------|-------------|
| 1 | Beginner | Understands basic concepts with guidance. |
| 2 | Intermediate | Applies skills independently in common scenarios. |
| 3 | Advanced | Solves complex problems with confidence. |
| 4 | Professional | Delivers industry-quality work consistently. |
| 5 | Expert | Demonstrates mastery, innovation, and leadership. |

---

# 8.7 Skill Categories

Skills may belong to one or more categories.

| Category | Examples |
|----------|----------|
| Technical Skills | Programming, APIs, Databases |
| AI Skills | Prompt Engineering, AI Automation |
| Design Skills | UI Design, UX Research |
| Business Skills | Marketing, Sales, Finance |
| Communication Skills | Writing, Presentation |
| Leadership Skills | Team Management, Decision Making |
| Analytical Skills | Data Analysis, Problem Solving |
| Professional Skills | Time Management, Collaboration |

---

# 8.8 Competency Evidence

Competencies should be validated using evidence.

Examples include:

- Practical Assessments
- Projects
- Assignments
- Portfolio Artifacts
- Presentations
- Peer Reviews
- Capstone Projects
- Certification Evaluations

---

# 8.9 Skill Relationships

```text
Knowledge
      │
      ▼
Skill
      │
      ▼
Competency
      │
      ▼
Assessment
      │
      ▼
Evidence
```

Each layer builds upon the previous layer.

---

# 8.10 Rules

The following rules apply:

- Every Module MUST teach one or more Skills.
- Every Track MUST develop multiple Competencies.
- Every Learning Outcome MUST be measurable.
- Every Competency MUST be assessable.
- Every Skill SHOULD be reusable across multiple learning experiences.
- Competencies MUST be supported by assessment evidence.

---

# 8.11 Common Mistakes

Avoid:

- Confusing knowledge with competency.
- Creating vague learning outcomes.
- Measuring completion instead of capability.
- Teaching skills without assessment.
- Defining competencies without observable evidence.
