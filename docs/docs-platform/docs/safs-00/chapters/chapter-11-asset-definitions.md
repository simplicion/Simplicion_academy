# Chapter 11 — Asset Definitions

> **Educational Assets support learning. They provide learners with additional resources, references, templates, tools, and media that enhance the learning experience without changing the instructional structure.**

---

# 11.1 Purpose

This chapter establishes the official definitions for Educational Assets used throughout Simplicion Academy.

Educational Assets are reusable supporting resources attached to Learning Units, Topics, Modules, or Tracks.

Assets improve understanding, productivity, practice, and long-term knowledge retention.

---

# 11.2 Educational Asset

## Definition

An Educational Asset is any reusable resource created or curated to support learning.

Assets supplement instructional content but are not instructional objects themselves.

---

## Characteristics

- Reusable
- Version Controlled
- Searchable
- Downloadable (when applicable)
- Metadata Driven
- Independently Managed

---

# 11.3 Asset Categories

Educational Assets are organized into standardized categories.

| Category | Purpose |
|----------|---------|
| Document | Written supporting material |
| Image | Visual reference |
| Diagram | Visual explanation |
| Video | Multimedia learning |
| Audio | Spoken learning material |
| Template | Reusable document or file |
| Checklist | Verification guide |
| Cheat Sheet | Quick reference |
| Worksheet | Guided learner activity |
| Dataset | Practice data |
| Code Sample | Technical implementation |
| Prompt Library | AI prompt collection |
| Case Study | Real-world example |
| Reference | External or internal learning source |
| Download | Supplemental file |
| Tool | Software or platform recommendation |

---

# 11.4 Document

## Definition

A Document is a written educational resource that provides detailed information beyond the core instructional content.

---

## Examples

- Guides
- Manuals
- Whitepapers
- Documentation
- Reference Notes

---

# 11.5 Image

## Definition

An Image is a static visual asset used to improve learner understanding.

Images should clarify concepts rather than decorate content.

---

## Examples

- Screenshots
- Illustrations
- Process Graphics
- Infographics
- UI Examples

---

# 11.6 Diagram

## Definition

A Diagram visually represents relationships, structures, workflows, or systems.

Diagrams simplify complex information and improve conceptual understanding.

---

## Examples

- Flowcharts
- Architecture Diagrams
- Mind Maps
- Entity Relationship Diagrams
- System Diagrams

---

# 11.7 Video

## Definition

A Video is a recorded visual learning resource that demonstrates concepts, procedures, or practical examples.

Videos complement written content and should not replace essential instructional text.

---

## Examples

- Tutorials
- Demonstrations
- Walkthroughs
- Screen Recordings
- Expert Interviews

---

# 11.8 Audio

## Definition

An Audio Asset is a spoken educational resource intended for listening.

---

## Examples

- Podcasts
- Interviews
- Narrations
- Audio Lessons

---

# 11.9 Template

## Definition

A Template is a reusable starting point that learners can adapt for practical work.

---

## Examples

- Business Canvas
- Resume Template
- Wireframe Template
- API Documentation Template
- Project Proposal Template

---

# 11.10 Checklist

## Definition

A Checklist is a structured list of items used to verify completion, quality, or readiness.

---

## Examples

- Project Submission Checklist
- Deployment Checklist
- UX Review Checklist
- Content Publishing Checklist

---

# 11.11 Cheat Sheet

## Definition

A Cheat Sheet is a concise reference summarizing essential concepts, commands, formulas, or best practices.

Cheat Sheets are intended for quick consultation rather than comprehensive instruction.

---

# 11.12 Worksheet

## Definition

A Worksheet is a guided learning resource containing structured exercises or activities.

Worksheets encourage active participation and reinforce learning.

---

# 11.13 Dataset

## Definition

A Dataset is a structured collection of information provided for analysis, experimentation, or practice.

---

## Examples

- CSV Files
- JSON Data
- SQL Dumps
- Research Data

---

# 11.14 Code Sample

## Definition

A Code Sample is a reusable implementation demonstrating a programming concept or technical solution.

Code Samples should prioritize readability, correctness, and educational value.

---

# 11.15 Prompt Library

## Definition

A Prompt Library is a curated collection of AI prompts designed to support learning, productivity, and practical implementation.

Each prompt should include:

- Objective
- Prompt Text
- Expected Output
- Usage Guidance

---

# 11.16 Case Study

## Definition

A Case Study is a structured analysis of a real or simulated scenario used to demonstrate practical application of concepts.

Case Studies should include:

- Context
- Problem
- Solution
- Outcome
- Lessons Learned

---

# 11.17 Reference

## Definition

A Reference is a trusted source of additional information supporting the learning experience.

References may be internal or external.

---

## Examples

- Official Documentation
- Standards
- Research Papers
- Books
- Technical Specifications

---

# 11.18 Download

## Definition

A Download is a file made available for learners to obtain and use during or after learning.

Downloads should be clearly versioned and maintained.

---

## Examples

- PDFs
- ZIP Archives
- Presentation Slides
- Source Files
- Project Files

---

# 11.19 Tool

## Definition

A Tool is a software application, platform, or service recommended to support learning or practical work.

Tools are referenced as learning resources and are not considered educational objects.

---

## Examples

- Code Editors
- Design Software
- AI Platforms
- Project Management Software
- Development Frameworks

---

# 11.20 Asset Metadata

Every Educational Asset MUST include the following metadata.

| Metadata | Required |
|----------|----------|
| Asset ID | Yes |
| Title | Yes |
| Asset Type | Yes |
| Version | Yes |
| Owner | Yes |
| Description | Yes |
| Status | Yes |
| Language | Yes |
| Creation Date | Yes |
| Last Updated | Yes |
| Related Learning Objects | Yes |
| License | Yes |

---

    │

---

# 11.22 Rules

The following rules apply:

- Every Asset MUST have a unique identifier.
- Every Asset MUST include required metadata.
- Assets SHOULD be reusable across multiple learning experiences.
- Assets MUST be version controlled.
- Outdated Assets SHOULD be reviewed or deprecated.
- Assets MUST support, not replace, instructional content.

---

# 11.23 Common Mistakes

Avoid:

- Uploading duplicate assets.
- Publishing outdated versions.
- Missing metadata.
- Embedding unsupported file formats.
- Creating assets without ownership.
- Treating assets as instructional content.

# Summary

Educational Assets are reusable supporting resources that enhance learning across Simplicion Academy.

By standardizing asset types, metadata, lifecycle, and governance, the academy ensures consistency, discoverability, maintainability, and long-term reuse of learning resources.

Future standards governing asset production, storage, publishing, licensing, and quality assurance MUST align with the definitions established in this chapter.
